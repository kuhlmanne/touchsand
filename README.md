# TouchSand

A celebratory beach landing page for the projects posted in the beach group chat, with a wall of sunset pictures.
Plain HTML, CSS and a little JavaScript. No tracking, no outside requests, no build step.

Live at <https://touchsand.kuhltura.net/>.

## What is in here

| File | What it is |
|---|---|
| `index.html`, `touchsand.css`, `touchsand.js` | The page |
| `projects.js` | The projects and the sunset pictures, edited by hand |
| `sunset/` | The pictures (re-saved without location data) |
| `CNAME` | The custom domain for GitHub Pages |

## Add a project or a picture

Add an entry to `projects.js`. Only projects with a full `https://` address get a **Dig in** button; the rest show as
washing ashore soon. Drop pictures into `sunset/` (strip the location data first) and list them in `SUNSETS`.

Type is the Kuhltura pairing: Futura-style headings and Georgia body, both from the visitor's own device.
