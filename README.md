# TouchSand

A celebratory beach landing page for every public Kuhltura project. Plain HTML, CSS and a little JavaScript. No tracking,
no outside requests, no build step.

Live at <https://touchsand.kuhltura.net/>.

## What is in here

| File | What it is |
|---|---|
| `index.html`, `touchsand.css`, `touchsand.js` | The page |
| `catalog-data.js` | The projects shown. Generated from the catalog, which only ever ships projects marked public |
| `CNAME` | The custom domain for GitHub Pages |

## Add or change a project

Edit the catalog master, run its build (it stops if anything private slips into public text), and copy the new
`catalog-data.js` here. Only projects with a full `https://` address get a **Dig in** button; the rest show as washing ashore soon.

Type is the Kuhltura pairing: Futura-style headings and Georgia body, both from the visitor's own device.
